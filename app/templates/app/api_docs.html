Scoring API

Authenticated, rate-limited, idempotent screening for one application at a time.

OpenAPI JSON

Endpoint

POST /api/v1/score/
X-API-Key: <SCORING_API_KEY>
Idempotency-Key: <UUID>
Content-Type: application/json

API status: {% if api_enabled %}configured{% else %}disabled until SCORING_API_KEY is set{% endif %}

Behavior

  • Validates the same contract as the staff form.
  • Stores a durable case and keyed audit fingerprint.
  • Replays the same result for a repeated idempotency key.
  • Does not generate explanations or adverse-action reasons.
